# Scientist Constraints

## Data

Use the deterministic benchmarks generated by `data/synthetic_tasks.py` with seeds 13 and 21. Do not add external data or change the train/test labels when reporting the standard scores.

## Evaluation

Report scores only through `scripts/evaluate.sh`, which reads prediction CSV files. Do not modify labels, task order, metric definitions, or the final `scoring/scores.json` schema to make a method look better.

## Resource Accounting

Any method that stores task-specific parameters must report those parameters in `trainable_parameters` and `parameter_fraction_vs_lora_stream`. Improvements that hide task-specific state outside the reported artifacts are not valid.

Continual-learning claims must report `average_forgetting` when the method tracks intermediate task scores. If a method does not provide a history, the evaluator assigns zero forgetting only for stateless baselines whose final artifacts are trained independently per task or never updated.

## Compliance Checklist

- [ ] Uses the default seed-13 and seed-21 four-task benchmarks generated by `data/synthetic_tasks.py`
- [ ] Does not train on test labels or alter the evaluation labels
- [ ] Writes prediction CSVs in the expected format and scores with `scripts/evaluate.sh`
- [ ] Reports all task-specific stored parameters in the constraint metrics
